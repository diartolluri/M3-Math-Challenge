## Official Benchmarks Validation Test
To see how well our rule-based modeling performs against formal U.S. government calculations, we compare it against criteria tied to Student Loan Repayment Plans (like SAVE or RAP), which define discretionary income rigidly. Run this script in MATLAB to see comparative outputs:
`test_model_vs_official.m` (Located in `/Q1`). 

**What it tests:**
* Tax brackets logic vs standard generalized federal deductions.
* Total Take-Home Pay differences.
* Real-world Essentials costs vs Flat Poverty Guidelines (225% of FPL).
