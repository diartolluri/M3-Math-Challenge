## M3 Maths Modelling Challenge Response - Team #18907

See the [project report](docs/M3%20Documentation.pdf) for the models and results.

| Folder | Contents |
| --- | --- |
| `Q1/`, `Q2/`, `Q3/` | MATLAB models and analyses for each question |
| `ProblemAndData/` | Original challenge brief and dataset |
| `Figs/` | Figures and supporting MATLAB scripts |
| `docs/` | Project report, past solutions, and exported code listings |
| `tools/` | Python scripts for generating code listings |

Run the listing scripts from the repository root, for example `python3 tools/merge_q1_code.py`. They write their output to the current directory.
